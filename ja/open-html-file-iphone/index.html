この方法が向いている場面

すでにファイルがあり、iPhoneやiPadで確実にプレビューしたいときの最短ルートです。

一致する検索意図

AIツール、Files、メール、ダウンロード、クラウドドライブから受け取ったHTMLファイルがあり、iOSではアイコン、ソース、または読みにくい表示になっている場合です。

iOSの標準ルート

Files、メール、Safariのダウンロード、AirDrop、クラウド、元のアプリから開き、共有またはOpen Inを使います。

ビューアの役割

Html Previewは.html, .htm, .xhtml用のローカルビューアです。アップロードや変換サイトを挟まずに開けます。

使わなくてよい場合

通常のWebリンクだけならSafariで十分です。Html Previewは、iOSで安定して表示できないローカルの.html、.htm、.xhtmlファイル向けです。

ファイルがMarkdownの場合

HTMLではなくMarkdownが生成された場合は、関連するiOSビューアのMd Previewを使います。
