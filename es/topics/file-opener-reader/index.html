Tienes un archivo HTML de búsquedas de abridor y lector y iOS muestra un icono, código sin renderizar o una vista poco legible.

Ruta nativa de iOS

Empieza en Files, Mail, descargas de Safari, AirDrop, una nube o la app de origen, y usa Compartir u Open In.

Papel del visor

Html Preview es el visor local dedicado para .html, .htm, .xhtml; evita subidas y flujos de conversión.
