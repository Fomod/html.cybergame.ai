When this is the right iOS fix

Use this route when the file already exists and you need a reliable preview path on iPhone or iPad.

Best-fit search intent

You have an HTML file from Notion exports and iOS shows an icon, raw code, or an unreadable preview.

Native iOS path

Start from Files, Mail, Safari downloads, AirDrop, a cloud drive, or the source app, then use Share or Open In.

Viewer role

Html Preview is the dedicated local viewer for .html, .htm, .xhtml; it avoids upload and converter workflows.

När du inte behöver den

Om du bara har en vanlig webblänk räcker Safari. Använd Html Preview när objektet är en lokal .html-, .htm- eller .xhtml-fil som iOS inte förhandsvisar tydligt.

Använd Md Preview, den kompletterande iOS-visaren för Markdown, när flödet skapar Markdown i stället för HTML.
