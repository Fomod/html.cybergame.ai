Vous avez un fichier HTML venant de outils IA, Files, e-mail, téléchargements ou cloud et iOS affiche une icône, du code brut ou une prévisualisation peu lisible.

Parcours iOS natif

Rôle du lecteur

Html Preview est le lecteur local dédié pour .html, .htm, .xhtml; il évite l'envoi de fichiers et les convertisseurs.
